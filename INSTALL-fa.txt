۱. پیشخوان ← افزونه‌ها ← نصب‌کننده: فایل varizet.ocmod.zip را بارگذاری و «نصب» کنید (نام فایل را تغییر ندهید).
۲. افزونه‌ها ← افزونه‌ها ← پرداخت‌ها ← «واریزت»: نصب، سپس ویرایش.
۳. محیط، کلید API و secret وب‌هوک را وارد کنید و «بررسی اتصال» را بزنید.
۴. آدرس وب‌هوک نمایش‌داده‌شده را در پنل واریزت ← وب‌هوک‌ها ثبت کنید.
۵. آدرس کران را هر ۵ دقیقه فراخوانی کنید (پشتیبان وب‌هوک).
